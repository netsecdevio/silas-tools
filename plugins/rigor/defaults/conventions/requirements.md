# Requirements Conventions

- Explicitly separate MVP scope from full vision in every requirements specification
- Prioritize every requirement as must-have, should-have, or nice-to-have
- Bug fix requirements must include a root-cause hypothesis and define regression test criteria — what specific behavior must the fix prevent from recurring
- Non-functional requirements must include quantitative targets where feasible (e.g., p95 latency ≤ 200 ms, uptime ≥ 99.9%) — qualitative NFRs ("the system should be fast") are acceptable only when measurement is genuinely impractical
